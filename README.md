# SauceDemo Playwright AI

Production-grade Playwright + TypeScript test framework for [SauceDemo (Swag Labs)](https://www.saucedemo.com/), built and maintained with agentic AI workflows using Claude Code.

> Work in progress. The framework is being built in small, reviewed steps; the full README (architecture, how to run locally, in Docker and in CI) lands at the end of Phase 0.

## Requirements

- Node.js 24 LTS (see `.nvmrc`)
